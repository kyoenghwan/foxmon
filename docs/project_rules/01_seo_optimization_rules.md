# Foxmon - SEO(검색 엔진 최적화) 특수 지침

이 문서는 Foxmon 프로젝트에서 검색 엔진 최적화(SEO)를 극대화하기 위해 코드를 작성할 때 반드시 지켜야 할 프론트엔드(Next.js) 규칙을 정의합니다.

## 1. 메타데이터 (Metadata) 규칙
모든 페이지는 구글 검색과 소셜 미디어(카카오톡 등) 공유 시 올바른 정보가 노출되도록 메타데이터를 필수적으로 가져야 합니다.

- **정적 페이지:** `layout.tsx` 또는 `page.tsx`에 `export const metadata: Metadata` 객체를 정의합니다.
- **동적 페이지 (`[id]` 등):** 페이지 컴포넌트 파일에 반드시 `export async function generateMetadata` 함수를 구현하여, DB에서 데이터를 읽어와 동적으로 제목과 설명을 구성해야 합니다.
- **필수 포함 항목:**
  - `title`: 페이지의 구체적인 제목 (예: `{공고제목} | 폭스몬`)
  - `description`: 160자 이내의 간결하고 핵심적인 설명 (HTML 태그 제거 필수)
  - `openGraph`: `og:title`, `og:description`, `og:siteName`, `og:locale: 'ko_KR'`
  - `keywords`: 롱테일 키워드 (유흥알바, 고수익알바 등) 포함 권장

## 2. 시맨틱 HTML (Semantic HTML) 규칙
검색 엔진 크롤러가 사이트의 구조를 명확히 이해할 수 있도록, 무분별한 `<div>` 사용을 지양하고 시맨틱 태그를 사용합니다.

- **`<main>`:** 페이지의 본문(핵심 콘텐츠)을 감싸는 최상위 태그로 사용 (페이지당 1개 필수).
- **`<section>`:** 논리적으로 독립된 콘텐츠 묶음(예: '최신 구인 공고', '프리미엄 배너 영역' 등)을 감쌀 때 사용.
- **`<article>`:** 하나의 완성된 독립적 콘텐츠(예: 구인 공고 카드 1개, 커뮤니티 게시글 1개)를 감쌀 때 사용.
- **`<nav>` / `<aside>`:** 내비게이션 바 및 사이드바 영역에 사용.
- **헤딩 태그 (`<h1>` ~ `<h6>`):** 페이지 당 `<h1>`은 가장 중요한 제목 1개만 사용하며, 계층 구조를 건너뛰지 않고 순차적으로 사용합니다.

## 3. 이미지 최적화 (Image Optimization) 규칙
구글 SEO 점수에 큰 영향을 미치는 LCP(최대 콘텐츠 렌더링 시간)를 개선하기 위한 이미지 규칙입니다.

- 가급적 Next.js의 `import Image from 'next/image'` 컴포넌트를 사용합니다.
- **`alt` 속성 필수:** 모든 이미지(특히 배너와 썸네일)에는 시각장애인 스크린 리더와 구글봇이 읽을 수 있는 명확한 `alt` 텍스트를 반드시 작성합니다. 의미 없는 장식용 이미지일 경우 `alt=""`로 둡니다.
- **`priority` 속성:** 화면 첫 진입 시(Above the fold) 가장 크게 보이는 메인 배너 이미지에는 `priority` 또는 `priority={true}` 속성을 추가하여 LCP를 최적화합니다.
