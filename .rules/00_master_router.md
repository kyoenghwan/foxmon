# 폭스몬 지침 라우터

작업·검증·권한의 원본은 루트 AGENTS.md다. 먼저 읽고 관련 스킬만 선택한다. 기술 구조는 PROJECT_GUIDE.md에서 확인한다.

- Atom: agent-kit/skills/foxmon-atom-design/SKILL.md
- UI: agent-kit/skills/foxmon-design-system/SKILL.md
- 색인·DB 문서: agent-kit/skills/foxmon-project-index/SKILL.md
- 인수인계: agent-kit/skills/foxmon-work-continuity/SKILL.md

기존 docs/project_rules의 배너·모바일·이미지 제약은 유지한다. 01~04 문서와 템플릿은 기술 참고이며 별도 점수/YAML 승인, 자동 커밋·push, 전체 입력 로깅, 형식적인 rollbackData 강제는 적용하지 않는다.

테스트 자격증명은 지침에 보관하지 않는다. 이전 문서에 있던 값은 이관하지 않았으며 Git 과거 이력이나 계정 자체가 정리되었다는 의미는 아니다.
