# 폭스몬 지침·스킬 사용

공통 규칙 원본은 AGENTS.md, 기술 안내는 PROJECT_GUIDE.md, 스킬 원본은 agent-kit/skills다. AGENTS.md가 관련 작업에서 읽을 경로를 지정한다. 전역 스킬 폴더와 LIFORY 원본은 변경하지 않았으며 앱 자동 스킬 등록은 검증하지 않았다.

새 PC에서는 실제 Git 상태와 CURRENT_STATE.md를 대조한다. 커밋하지 않은 파일은 다른 PC로 자동 전달되지 않는다. .env·키·계정 정보는 이 패키지에 넣지 않는다.

2026-09-08 LIFORY(로컬 diary)의 AGENTS.md, PROJECT_GUIDE.md 및 네 agent-kit 스킬을 참고했다. 공통 지침 단일 관리와 역할별 스킬, 인수인계는 가져왔다. LEVEL 폐지·Vite·다중 테마·기억 모델·통합 schema.sql 경로는 가져오지 않았다. 폭스몬의 사용자 LEVEL 규칙, Next.js, 광고/포인트, 배너/모바일 제약에 맞췄다.

기존 .rules 기술 문서는 유지하면서 충돌하는 작업 절차에 우선순위 안내를 추가했다. 자동 push 규칙과 평문 테스트 자격증명은 현행 안내에서 제거했다. Git 이력과 계정 자체는 변경하지 않았다.
